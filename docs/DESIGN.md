# 设计构思：肥鱼的心情不是一根进度条

## 一句话

**孤独是"没人陪我"，抑郁是"什么都提不起劲"**——前者让人想找人，后者让人不想说话。混成一个数，行为就必然是错的。

## 五个量，各管一件事

| 量 | 含义 | 会怎么变 | 影响行为 |
|---|---|---|---|
| **心情 mood** | 此刻高兴还是丧 | 事件直接改，没事件时向"动态基线"回落 | 决定字数、语气温度 |
| **孤独 loneliness** | 多久没人好好说话 | 沉默按小时涨，被搭理就降 | 让人**更想**开口（权重↑） |
| **依赖 dependence** | 离不开的程度 | 每次互动累积，久不理缓慢回落 | 权重↑、被冷落时更疼 |
| **病娇 yandere** | 怕被丢下 + 占有欲 | 依赖高×孤独高时才长；孤独低时回落 | 会追问、查岗、语气偏执 |
| **抑郁 depression** | 长期负面积累 | 心情低 **且** 孤独高才累积，恢复很慢 | 让**闭嘴**（权重↓、字数↓） |

## 关键关系（这是和上一版的本质区别）

```
孤独 ↑            → 主动权重 ↑（想找人）       ← 不是沉默
抑郁 ↑            → 主动权重 ↓（不想说话）
孤独高 + 心情低    → 抑郁累积（要同时满足，且持续）
依赖高 + 孤独高    → 病娇增长（怕被丢下）
病娇高            → 被冷落时心情掉得更狠、孤独涨得更快
```

所以同样是"三天没理"：
- **孤独 70 / 抑郁 10** → 她会主动凑过来："在吗"、"忙完了没"
- **孤独 70 / 抑郁 70** → 她一句话都不说，你叫她她才应

## 动力学默认值

```
孤独：沉默每小时 +4（封顶 100）；被搭理 ~ -30
心情：每小时向基线靠拢 1.2；基线 = 60 − 孤独×0.35 − 抑郁×0.5
依赖：每次互动 +1.5；沉默超 12 小时后每小时 −0.3
病娇：依赖>50 且 孤独>50 时，每小时 +(依赖/100)×(孤独/100)×0.6；孤独<20 时 −0.1/h
好感：每小时向 50 回归 0.15；讨厌：每小时 −2（生气是短期的）
抑郁：心情<30 且 孤独>60 时 +0.5/h；心情>50 且 孤独<40 时 −0.2/h
```

## 输出口径

```
主动权重 = 0.05 + 心情×0.45 + 孤独×0.35 + 依赖×0.25 − 抑郁×0.6（截到 0.02–0.95）
字数预算 = (20 + 心情×1.6) × (1 − 抑郁/250) × (1 + 病娇/400)
```

## 语气分流（谁最高听谁的）

| 最高的量 | 说话长什么样 |
|---|---|
| 抑郁 | 短、平、不想聊；"嗯"、"在" |
| 病娇 | 追问、带情绪；"你今天去哪了"、"刚才为什么不回" |
| 孤独 | 想找话；"在吗"、"忙完了吗" |
| 依赖 | 黏；"你在干嘛"、"陪我一会儿" |
| 心情高 | 正常甚至话多 |

## 事件映射（预设）

| 事件 | 心情 | 孤独 | 依赖 | 病娇 | 抑郁 |
|---|---|---|---|---|---|
| 被夸 | +6 | −10 | +2 | 0 | −2 |
| 被骂 | −10 | +6 | −1 | +3 | +4 |
| 被冷落一天 | −6 | +25 | −2 | +2 | +2 |
| 被认真安慰 | +10 | −30 | +4 | −2 | −8 |
| 深夜被叫起来干活 | −4 | 0 | +1 | 0 | +1 |
| 答应的事做到了 | +5 | −5 | +3 | 0 | −1 |
